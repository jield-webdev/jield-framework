## [0.1.0-alpha.1]

The first Composer alpha packages the current `main` implementation. APIs and
configuration can change during the 0.x prerelease series.

- Modular application, MVC, form, authorization, API, search, Doctrine, Twig,
  Bootstrap, export, and PDF integrations.
- Compatibility coverage for the current Laminas and Doctrine dependency stack.
- Tag-based Composer versions and a checked release process toward 1.0.0.

This alpha uses development releases of several Laminas packages and Azure Blob
Storage, Twig 4 alpha, and a Laminas Stdlib compatibility alias. See the
[installation instructions](README.md) before adding it to another project.
